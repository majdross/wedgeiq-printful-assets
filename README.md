# WedgeIQ Printful Assets

Production asset repository for WedgeIQ apparel and Printful automation.

## Structure
- `tees/it-series/` — FLIGHT IT, SPIN IT, COMPRESS IT, FLOP IT, STICK IT
- `tees/wedgeiq-card/` — WedgeIQ Card tee artwork
- `logos/` — Signature IQ and Primary WedgeIQ marks
- `embroidery/` — embroidery-ready logo assets
- `polos/` — polo-specific artwork
- `quarter-zips/` — quarter-zip artwork
- `hoodies/` — hoodie artwork
- `phase-2/` — future outerwear, towels, crewnecks, duffle
- `manifest.json` — asset and placement map for automation

## Brand basics
- IQ Navy: `#09192D`
- White: `#FFFFFF`
- Black: `#000000`
- Tagline: **THINK BETTER. PLAY BETTER.**

## Printful workflow
1. Store approved production files here.
2. Serve them over GitHub Pages/public HTTPS.
3. Use their URLs in the Printful Files API.
4. Build/sample product templates in Printful.
5. Publish approved products to Shopify.

> Note: `STICK IT` is the current product direction. Any legacy `STIFF IT` source art must be updated before production.
